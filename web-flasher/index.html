HARDWARE REQUIREMENT

小提醒：需要 EnviroSense 載板

韌體專為搭載 SHT40 溫濕度感測器、電池電壓分壓與閘控、電池保護電路的 EnviroSense 載板設計。單獨的 XIAO ESP32C6 無法正常量測。

Requires the EnviroSense carrier board with SHT40, gated battery divider and battery protection. A bare XIAO ESP32C6 will not measure correctly.

四步，完成連接Before you start

01 — 04
  1. 用 USB 線連接電腦

    請使用可傳輸資料的 USB 線，僅供充電的線材無法燒錄。

  2. 讓裝置進入燒錄模式
    按住BOOT→ 按一下RESET→ 放開BOOT

    節點平常處於深睡模式，USB 序列埠不會出現，請先完成這個步驟。

  3. 選擇序列埠，開始燒錄

    點擊「連接並燒錄」，在視窗中選擇 USB JTAG/serial debug unit 或名稱類似的 COM port。

  4. 重新啟動，完成設定

    燒錄完成後按一次 RESET。首次安裝時，請在 LED 亮起後 10 秒內再按一次 RESET，開啟設定頁。

燒錄前，再確認一下Erase & settings

  • 清除 flash 會重設設定

    安裝時會詢問是否清除整顆 flash。清除後，WiFi 與 MQTT 設定會消失，需要重新設定。

  • 更新韌體，也可以保留設定

    若只想更換韌體，請不要勾選清除，或使用離線工具的 update 模式。

  • 確認使用正確的硬體

    僅支援 XIAO ESP32C6，其他晶片將無法燒錄。裝置也需搭配 EnviroSense 載板才能正常運作。

透過 USB，在你的電腦上完成燒錄。網頁只提供韌體檔；韌體不含任何 WiFi / MQTT 登入資料，請在燒錄後透過設定頁填寫。

LET’S GET CONNECTED

找不到你的裝置？

先確認以下三件事，再重新選擇 USB 序列埠。

  • 換用可傳輸資料的 USB 線，並確認接頭已插緊。
  • 按住 BOOT → 按一下 RESET → 放開 BOOT，進入燒錄模式。
  • 關閉正在使用序列埠的其他程式，再選擇 USB JTAG/serial debug unit。
