EnviroSense 網頁燒錄

把 HA 版韌體 0.2.2-ha 直接燒進 Seeed XIAO ESP32C6，不用安裝任何軟體。
Flash the EnviroSense HA firmware to a Seeed XIAO ESP32C6 straight from your browser.

這個瀏覽器不支援 Web Serial。請用桌面版 Chrome 或 Edge，或改用專案 release 資料夾裡的離線工具 flash.bat。
This browser has no Web Serial. Use desktop Chrome or Edge, or the offline flash.bat tool. 需要 HTTPS 連線（或 localhost）才能使用序列埠。 / Serial access needs HTTPS.

燒錄前 / Before you start

  1. 用可傳資料的 USB 線接上電腦
  2. 讓晶片進燒錄模式：按住 BOOT → 按一下 RESET → 放開 BOOT （節點平常在深睡，USB 序列埠不會出現）
  3. 按上面的按鈕，在彈出的視窗選擇 USB JTAG/serial debug unit（或名稱類似的 COM port）
  4. 燒完按一次 RESET；首次安裝：LED 亮後 10 秒內再按一次 RESET → 開設定頁

⚠ 清除與設定 / Erase & settings

  • 安裝時會詢問是否清除整顆 flash。清除後 WiFi / MQTT 設定會消失，要重新設定。
  • 只想換韌體、保留設定：不要勾選清除，或改用離線工具的 update 模式。
  • 只支援 XIAO ESP32C6，燒在其他晶片會失敗。
